# Glossary and Abbreviations

## Terms

| Term | Definition |
| --- | --- |
| **Brain Directory** | Per-conversation folder (`<root>/brain/<uuid>/`) storing Antigravity transcripts, step outputs, and artifacts. |
| **Cached Input Tokens** | Prompt tokens served from provider prompt cache (`cache_read_tokens`) and billed at reduced cache-read rates. |
| **CLI** | Command-Line Interface (`~/.gemini/antigravity-cli`). |
| **CSVW** | World Wide Web Consortium (W3C) Comma-Separated Values on the Web metadata standard. |
| **Feature** | Logical unit of work within a project, resolved from Work Package ID, git branch, or root conversation title. |
| **IDE** | Integrated Development Environment (`~/.gemini/antigravity`). |
| **JSONL / NDJSON** | Newline-Delimited JavaScript Object Notation; one flat JSON object per line for streaming and VisiData (`vd -f jsonl`). |
| **Subagent** | Child conversation spawned by a parent coordinator conversation, often inside an isolated git worktree. |
| **Thinking Tokens** | Reasoning tokens generated by frontier models prior to visible response output, included inside `output_tokens`. |
| **Uncached Input Tokens** | Prompt input tokens not served from cache (`input_tokens`) and billed at standard input rates. |
| **VisiData (`vd`)** | Interactive terminal spreadsheet and tabular data exploration tool (`saul.pw/VisiData`). |
| **Work Package (`WP`)** | Bounded implementation slice identifier such as `WP-19` or `ORGFMT-WP-40`. |
