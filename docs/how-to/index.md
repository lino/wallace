# How-to Guides

How-to guides provide direct, goal-oriented steps to solve specific problems. They assume you have already installed `wallace` and run a basic report.

## Auditing and Analysis

| Guide | Goal |
| --- | --- |
| [Audit Timeframes and Task Spend](audit-timeframes-and-tasks.md) | Filter spend by calendar or rolling windows, group by period, and query tasks or single conversations. |
| [Browse and Read Conversations](browse-and-read-conversations.md) | Filter conversations in the interactive TUI or export transcripts as plain text and JSON. |
| [Configure Pricing and Session Paths](configure-pricing-and-paths.md) | Customize model rates, point to alternate session directories, or disable a provider. |
| [Explore Ledgers in VisiData](explore-in-visidata.md) | Install the VisiData plugin, pivot multi-sheet SQLite workbooks, and stream JSONL. |

## Operations and Maintenance

| Guide | Goal |
| --- | --- |
| [Deploy the Prometheus Exporter](deploy-prometheus-exporter.md) | Run `wallace` in Docker Compose or export textfile collector metrics for Prometheus. |
